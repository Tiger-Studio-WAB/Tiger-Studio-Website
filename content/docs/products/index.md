# Products

Public work is listed on [Products](/products). Each card is either a studio page or a GitHub repository.

## On this hub

- **Proj.Help** — ideas and replies, on [Join](/join)
- **Docs** — this handbook, from the `docs` repository
- **Support** — help and issues, on [Support](/support)

## On GitHub

Repositories in the [Tiger Studio organization](https://github.com/Tiger-Studio-WAB) appear on Products as they are created. Set a homepage on the repo if the project has a live site.

## Add a product page here

Create `products/your-product.md` in the docs repo. Follow [How to format docs](/docs/how-to-format).
