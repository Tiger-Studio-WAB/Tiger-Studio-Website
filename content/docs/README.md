# Tiger Studio docs

These pages are the studio handbook. The layout follows the same idea as Meta for Developers and Microsoft Fabric docs: a left-hand section list, one page per Markdown file, and folders as topics.

## How this site is built

| In the docs repo | On the website |
| --- | --- |
| A folder | A sidebar section |
| `index.md` or `README.md` in that folder | The section landing page |
| Any other `.md` file | A page in that section |
| `_category.json` | Optional section label and order |

Add a folder, add Markdown, and the page appears. See [How to format docs](/docs/how-to-format).
