# Getting started

Tiger Studio is a student passion club. This website is the front door: products, an ideas board, docs, and support.

## What you can do

1. Browse [Products](/products) to see public repositories and tools.
2. [Join](/docs/getting-started/join) to post an idea or reply on Proj.Help.
3. Read these docs when you are shipping or writing guides.
4. Use [Support](/support) only when you need help, not when you are learning how something works.

## The two GitHub repos

- [`docs`](https://github.com/Tiger-Studio-WAB/docs) — Markdown folders that become this handbook
- [`support`](https://github.com/Tiger-Studio-WAB/support) — issue templates and help copy for the Support page

Add a folder in `docs` to add a section. See [How to format docs](/docs/how-to-format).
