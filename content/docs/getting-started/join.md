# Join the ideas board

Proj.Help lives on this site under [Join](/join).

## Sign in

Use **GitHub** or **Microsoft**. GitHub is the path that does not need school admin approval.

After you sign in you can:

- Post an idea you want help with
- Reply if you can help
- Switch the UI between English and Chinese

## If sign-in does not finish

That is a Support problem, not a docs problem. Open [Support](/support) and file an issue.
